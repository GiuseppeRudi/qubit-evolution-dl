\begin{abstract}

Quantum computing has gained strong interest in recent years, but simulating many interacting qubits is slow and expensive because the system grows very quickly with the number of qubits and its behaviour is probabilistic. In this project, we use deep learning to learn qubit time-series dynamics from short sequences and to predict future ones. The same pipeline can also fill in missing data (imputation) and is controlled by a single configuration file, so we can change preprocessing, training, and evaluation without editing the code.
Our results show that learning the correlation patterns between qubits is challenging, which limits the precision of the predictions. For short forecasting horizons, the models can capture the overall trend and direction of the dynamics, but it does not match the target trajectory perfectly. As the prediction horizon increases, the performance degrades exponentially.

\end{abstract}
